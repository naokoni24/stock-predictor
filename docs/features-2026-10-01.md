# シグナル変化・保有株確認・ウォッチリスト・AI成績分析

## シグナル変化一覧

- ホームの「前回更新からのシグナル変化」、またはメニューの「シグナル変化」から確認する。
- 終値が保存された最新市場日と、その直前の市場日を比較する。両日に有効な終値がある銘柄だけを比較し、分析対象への初登場・対象からの脱落・価格欠損を変化として扱わない。
- テクニカルとAIの変化は別々に表示する。保有中の銘柄を先に並べる。
- AIスコア差はモデル世代が同じ場合だけ表示する。世代変更時はその旨を表示する。

## 保有株の確認優先度

ポートフォリオに、保有株を確認する順序と理由を追加した。
損切り目安への到達（取得単価−8%）、テクニカル売り候補、価格/シグナルの更新待ち、損切りまで3%以内の下落、同一モデルでのAIスコア0.10以上低下の順で並べる。
古い価格から損切り到達を新規判定したり、古いシグナルを最新の売り判定として表示したりしない。
同じ銘柄の複数保有は、取得単価が違う可能性があるため保有行単位で判定する。自動売買は行わない。

## 個人ウォッチリストとアラート

1. Supabase SQL Editorで `supabase/add_personal_watchlists.sql` を実行する。既存データは変更しない。再適用可能。
2. メニューの「ウォッチリスト」から登録銘柄を検索して追加する。銘柄詳細の追加ボタンでも登録できる。
3. 上限価格・下限価格（任意）とシグナル変化の通知有無を設定する。「アラート条件を変更」から編集できる。

- 1人30銘柄まで。DBの制約・トリガーでも上限を確認する。同一銘柄の重複登録は禁止。
- RLSで本人の行だけ読み書きできる。未認証ユーザーには権限を付与しない。所有者・登録日時はクライアントから変更できない。
- 最新市場日の終値が上限以上/下限以下なら「現在のアラート」に表示する。価格条件を満たしている間は表示を継続する。
- シグナル変化は直近2市場日の比較で判定する。登録日より前の比較は通知しない。次回更新で条件に該当しなくなれば表示から外れる。
- メール・プッシュ通知は使わず、アプリを開いて確認する。新しい常駐処理・有料API・外部通知サービスは追加していない。
- 日次分析の優先順は固定銘柄→保有株→ウォッチリスト→前回シグナル→スクリーナー→JPX補充。全体150銘柄を維持する。
- ウォッチリストは全ユーザー合算で先に登録された最大30ユニーク銘柄を追加候補にする（読み取り上限1000行）。固定/保有株で150銘柄に達した場合や、合算30枠を超えた場合は対象外になりうる。画面は古いデータに「更新待ち」を表示し、古い市場日の価格アラートを出さない。
- SQL未適用時はウォッチリスト画面で案内を表示し、日次バッチはウォッチリストの取得だけをスキップする。

## AI本番成績の条件別分析

- ホームの成績カード、または「AI成績」から表示する。
- 決済日基準の直近30日/90日を選択し、スコア帯・業種・モデル世代ごとの件数、勝率、平均ネット超過リターンを確認する。
- `evaluation_version=next_open_stop_excess_v1` の確定実績のみ集計。旧評価定義・未来日・null/非有限の成績は混ぜない。1000行を超えてもページングして集計し、取得失敗時は部分的な成績を表示しない。
- `net_return`は業種/TOPIXに対する超過リターンから往復コスト0.2%を控除した小数値で、表示時に100倍して%へ変換する。勝率はこの値が正の割合で、生の株価上昇率ではない。
- 20件未満は「少数」と表示。モデル世代ごとの期間差や、同日に発生した候補の相関にも留意する。AIスコアは相対順位で、確率ではない。
- PCは表、スマホはカードで全指標を表示する。

## 検証手順

通常の回帰テストは `npm test` と `PYTHONPATH=scripts python -m unittest discover -s scripts/tests -v`。
`npm run lint`、`npx tsc --noEmit`、`npm run build`、`git diff --check` も実行する。

SQLの検証は、本番DBに接続せずPGliteの一時DBで実施できる。プロジェクトの依存を増やさない例:

```bash
npm install --prefix /private/tmp/stock-feature-test --no-audit --no-fund --package-lock=false @electric-sql/pglite
PGLITE_TEST_MODULE=/private/tmp/stock-feature-test/node_modules/@electric-sql/pglite/dist/index.js node scripts/verify_watchlist_sql.mjs
```

SQL再適用、未認証拒否、2ユーザー間の読み書き分離、本人CRUD、登録上限、価格制約、所有者/登録日時の変更拒否、バッチの読み取りを確認する。

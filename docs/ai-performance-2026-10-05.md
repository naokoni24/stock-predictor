# AI本番成績が悪い原因の調査（2026-10-05）

本番の実績台帳では、9月のAI買い候補が213件・勝率31%・平均ネット超過リターン-2.49%だった。バックテスト（+0.34%）との乖離の原因を、本番データ（公開キーで読み取りのみ）とyfinanceの株価で切り分けた。

## 結論

1. **主因は実績台帳の業種平均（ベンチマーク）の計算の偏り（不具合、修正済み）**。候補自身のリターンは台帳と再計算で全357件一致した。一方、台帳の業種平均は平均+2.09%で、正しい計算では+0.38%だった。
2. 比較銘柄が「シグナル日以降も6営業日、日次分析対象（150銘柄）に残った銘柄」に限られていた。分析対象はスクリーナー（値上がり率・出来高上位）で日々入れ替わる。このため急騰が続いた銘柄ほど比較対象に残り、将来の値動きに依存した生存バイアスが生じていた。例: 9/3陸運業は9082.T（+56%）を含む3銘柄で業種平均+27.9%、9/24サービス業は9246.T（+99%）・6533.T（+58%）等を含んでいた。学習時の±30%打ち切りもなかった。
3. 学習と同じ定義（シグナル日の分析対象で業種平均、比較銘柄は±30%打ち切り）で再計算すると、6/29〜9/24の848件は勝率47.8%・平均ネット超過+0.37%。バックテストとほぼ一致する。月別は7月+0.63%、8月+0.72%、9月-0.31%。
4. AIスコアの順位付けには本番でも予測力がある。分析対象全銘柄での日次順位相関（IC）は8月+0.095、9月+0.167（正の日94%）。9月はスコア上位20%が+0.72%、下位20%が-0.82%。

## 9月が弱い理由（モデル設定の課題、未変更）

9月は、フィルターなしでスコア上位から選んだ場合が+0.99%（勝率56%）だった。一方、実際の買い候補は-0.37%で、見送りフィルターが上位銘柄を外していた。

| 見送り理由（しきい値超え銘柄） | 8月 | 9月 |
| --- | --- | --- |
| アンサンブル不一致が大きい（>0.10） | n=221 +1.20% | n=221 +1.03% |
| 平均売買代金が不足 | n=38 +1.99% | n=247 -0.14% |
| 短期下落が深い | n=38 -0.59% | n=174 +0.44% |
| 上ヒゲで押し戻されている | n=16 +0.07% | n=84 -1.72% |

（値は台帳v1とは異なる簡易ベンチマークでの5営業日超過リターン、コスト控除前）

- 「アンサンブル不一致」による見送りは2か月とも逆効果で、最も一貫している。本番モデルが不一致上限0.10を採用した際の検証結果は、上限なし+0.16%、0.04: +0.06%、0.06: -0.16%、0.08: -0.03%、0.10: +0.70%、0.12: +0.44%と単調でなかった。ノイズへの過適合の可能性が高い。10/2の再学習候補は「上限なし」を選んでいる。
- 本番モデルは市場局面neutralで共通しきい値を-0.35下げる設定。検証では平均+0.18%と+0.24%の小差で採用されており、根拠が弱い。
- ただし評価期間は約2か月で、5営業日保有が重なるため独立な標本は少ない。週別では、スコア上位の方が実際の候補より良い週は8週中5週だった。

## 修正内容

- 評価定義を `next_open_stop_excess_v2` に更新した。比較銘柄はシグナル日の分析対象（その日のsignals）に固定し、学習と同じく±30%で打ち切る。分析対象から外れた候補・比較銘柄の価格はyfinanceで補完し、DBには保存しない。
- 比較銘柄の価格取得率が80%未満の日は確定せず、次回へ持ち越す（偏った平均での確定を防ぐ）。
- 1回の実行で確定するのは最大8シグナル日（新しい順）。過去100日分のv2再計算は約1週間の日次実行で完了する。それまでAI成績画面は件数が少なく表示される。
- 本番相当の試行（保存なし）: 初回8日分で補完対象334銘柄中330銘柄を取得し、候補163件すべて確定。
